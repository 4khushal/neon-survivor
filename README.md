# Neon Survivor

A fast-paced 2D browser survival game featuring neon visuals, enemy waves, weapon upgrades, and progressively challenging gameplay.

## Features

- Neon-style 2D arena
- Enemy waves and survival gameplay
- XP collection and level progression
- Upgrade system and weapon evolution
- Multiple weapons, including Rapid Pulse, Spread Shot, Piercing Bolt, and Plasma Burst
- Pause, restart, and mute controls

## Controls

| Key / Input | Action |
|---|---|
| WASD / Arrow Keys | Move |
| Mouse | Aim |
| Left Click | Shoot |
| ESC | Pause |
| M | Mute / Unmute |

## Installation

Make sure Node.js and npm are installed.

```bash
git clone https://github.com/4khushal/neon-survivor.git
cd neon-survivor
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

## Build and Test

```bash
npm run build
npx playwright test
```
